## Capture Environment & Instructions

1. Launch emulator or device with resolution **1080 x 2400 px (420 dpi)**.
2. Set device theme to **Light Mode** for primary store screenshots and **Dark Mode** for secondary set.
3. Ensure synthetic test account (`scholar@example.com`) is active to display realistic practice scores and bookmark badges.
4. Execute `adb shell screencap -p /sdcard/screen_1.png` and pull images into `store_assets/screenshots/`.
